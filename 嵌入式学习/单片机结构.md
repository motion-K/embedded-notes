# 单片机笔记
## 单片机相关知识
1. 单片机架构发展历程
   早期20世纪70-80年代出现4位/8位单片机，采用哈佛结构（Harvard Architecture）或改进型哈佛结构，大部分使用CISC复杂指令集，支持非常灵活的内存寻址模式，方便汇编程序员编写紧凑的代码，程序空间和数据空间分离，后续出现RISC（精简指令集）指令长度固定、译码电路极其简单，大部分晶体管都可以用来做计算单元或缓存，这使得它能够做到极低的功耗、极小的体积和极低的成本，此时单片机运算能力仍然较弱；
   ::: info tip
    “8位”或“16位”这个指标，最核心指的是 CPU 的数据总线宽度（即字长，Word Size）。它直接决定了处理器处理数据的基本能力和规模。
   :::
   90年代出现8位/16位高性能单片机，采用RISC，引入片上FLASH，强化了低功耗设计；2000年后，32 位 ARM Cortex-M 架构成为主流，引入了 冯·诺依曼结构或统一总线架构 的先进变体，拥有极高的代码密度和 32 位数据处理能力。
2. 微型计算机系统（单片机硬件系统）
   1.  中央处理器（微处理器）：单片机的运算和控制核心，主要负责取指令、译码并按时序执行，主要组成：算术逻辑单元 (ALU)、控制单元 (CU)、寄存器组；
   2.  存储器：负责存放程序指令和运行数据，主要分为两类：程序存储器（ROM）、数据存储器（RAM）；
   3.  输入/输出端口（I/O port）：所有与外部物理世界交互或扩展硬件功能的片上模块，都统一归入 I/O 外设接口范畴；
   4.  总线：连接各个部件间的一组公共信号线，按传输信号的性质通常划分为三类；数据总线（Data Bus, DB）： 双向总线，传输 CPU 读写的数据和指令字、地址总线（Address Bus, AB）： 单向总线，用于指定访问哪个存储单元或外设寄存器、控制总线（Control Bus, CB）： 传输读写控制信号、时钟脉冲、复位信号以及中断请求等。
3. 单片机软件系统
   1.  系统软件：芯片支撑层 (Startup/CMSIS)、板级抽象与驱动层 (BSP/HAL)、中间件/系统调度层
   2.  应用软件；应用层 (App)
4. 计算机语言与程序设计
   计算机语言包括：机器语言、汇编语言、高级语言。程序设计的步骤为；确定数据结构、确定算法、编程、调试、整理并总结。算法要满足；可执行性、确定性、有穷性、输入、输出。
