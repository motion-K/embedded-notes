# 单片机笔记
## 单片机相关知识
1. 单片机架构发展历程
   早期20世纪70-80年代出现4位/8位单片机，采用哈佛结构（Harvard Architecture）或改进型哈佛结构，将程序存储空间和数据存储空间进行区分。 
   早期使用CISC复杂指令集，支持非常灵活的内存寻址模式，方便汇编程序员编写紧凑的代码，后续出现RISC（Reduced Instruction Set Computer，精简指令集计算机），指令长度固定、译码电路极其简单，大部分晶体管都可以用来做计算单元或缓存，这使得它能够做到极低的功耗、极小的体积和极低的成本；
   ::: info tip
    “8 位”“16 位”“32 位”通常主要描述处理器的字长以及主要数据处理宽度，但不能简单等同于数据总线宽度。例如 STM32F103 所使用的 Cortex-M3 属于 32 位处理器，但 MCU 内部不同总线的宽度和功能并不一定都相同。因此需要区分：
    - CPU 字长：与通用寄存器、ALU 等主要数据处理能力有关。
    - 数据总线宽度：表示一次可以传输的数据宽度。
    - 地址总线宽度：决定能够表示的地址范围。
    三者相关，但并不是同一个概念。
   :::
   20世纪90年代后，8位/16位高性能单片机进一步发展，采用RISC，引入片上FLASH，强化了低功耗设计；21世纪以后，32 位 ARM Cortex-M 架构成为主流，引入了 冯·诺依曼结构或统一总线架构 的先进变体，拥有极高的代码密度和 32 位数据处理能力。
2. 微型计算机系统（单片机硬件系统）
   1.  中央处理器（微处理器）：单片机的运算和控制核心，主要负责取指令、译码并按时序执行，主要组成：
    - 算术逻辑单元 (ALU)
    - 控制单元 (CU)
    - 寄存器组；
   2.  存储器：负责存放程序指令和运行数据，主要分为两类：
    - 程序存储器：用于存放程序代码，例如 Flash、ROM。
    - 数据存储器：用于存放运行过程中的数据，例如 RAM。
   3.  输入/输出端口（I/O port）：GPIO（General Purpose Input/Output）用于实现 MCU 与外部数字信号之间的输入和输出。除 GPIO 外，现代 MCU 通常还集成大量片上外设，例如：
    - USART / UART
    - SPI
    - I²C
    - ADC
    - 定时器（TIM）
    - USB
    - DMA
    - RTC
   4.  总线：连接各个部件间的一组公共信号线，按传输信号的性质通常划分为三类：
    - 数据总线（Data Bus, DB）： 双向总线，传输 CPU 读写的数据和指令字。
    - 地址总线（Address Bus, AB）： 单向总线，用于指定访问哪个存储单元或外设寄存器。
    - 控制总线（Control Bus, CB）： 传输读写控制信号、时钟脉冲、复位信号以及中断请求等。
3. 单片机软件系统
   1.  系统软件：芯片支撑层 (Startup/CMSIS)、板级抽象与驱动层 (BSP/HAL)、中间件/系统调度层
   2.  应用软件；应用层 (App)
4. 计算机语言与程序设计
   计算机语言包括：机器语言、汇编语言、高级语言。程序设计的步骤为；确定数据结构、确定算法、编程、调试、整理并总结。算法要满足；可执行性、确定性、有穷性、输入、输出。
